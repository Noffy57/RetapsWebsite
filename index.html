Вопросы

FAQ

Приложение безопасно?
Retaps работает полностью локально и не передаёт данные на сторонние серверы. Всё соединение — по Wi-Fi внутри вашей сети.
Почему Windows блокирует файл?
SmartScreen срабатывает на приложения без платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
Телефон не видит компьютер
Убедитесь, что оба устройства в одной Wi-Fi сети и Retaps запущен на вашем ПК. Проверьте настройки брандмауэра.
Работает ли без интернета?
Да. Нужен только локальный Wi-Fi. Интернет не используется ни при подключении, ни при передаче данных.
