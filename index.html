FAQ

Безопасно ли приложение? ▼
Retaps работает локально и не передаёт данные на сторонние серверы. Исходный код открыт – GitHub (ссылка появится позже).
Почему Windows блокирует файл? ▼
Это происходит из-за отсутствия платной цифровой подписи. Нажмите «Подробнее» -> «Выполнить в любом случае». Мы работаем над получением сертификата.
Телефон не видит компьютер ▼
Убедитесь, что оба устройства в одной Wi-Fi сети и Retaps Server запущен. Проверьте настройки Брандмауэра – он не должен блокировать входящие соединения для Retaps.
