Политика конфиденциальности

Приложение: Retaps Дата вступления в силу: 28 апреля 2026 г. Сайт: [https://retaps-app.ru/]

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») разработана в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» (с учётом изменений, вступивших в силу в 2025–2026 годах, в том числе ФЗ № 420-ФЗ, № 23-ФЗ, № 233-ФЗ, № 281-ФЗ) и описывает, как разработчик приложения Retaps (далее — «Разработчик») обеспечивает соблюдение прав пользователей в области персональных данных.

Используя приложение Retaps (далее — «Приложение») или посещая сайт (далее — «Сайт»), вы соглашаетесь с условиями настоящей Политики.

2. Кто является оператором персональных данных

Разработчик настоящего Приложения действует как физическое лицо. Приложение распространяется бесплатно, без сбора, хранения или обработки персональных данных пользователей со стороны Разработчика.

Поскольку Разработчик не осуществляет обработку персональных данных в значении, установленном ст. 3 ФЗ-152, регистрация в Реестре операторов персональных данных Роскомнадзора в текущей модели распространения Приложения не требуется.

Контактная информация:

  • Сайт: [https://retaps-app.ru/]
  • Электронная почта: [retaps.ru@gmail.com]

3. Какие данные Разработчик не собирает

Разработчик подтверждает, что:

  • не собирает никаких персональных данных пользователей;
  • не ведёт серверной инфраструктуры для хранения данных;
  • не использует системы аналитики, трекинга или телеметрии в Приложении;
  • не передаёт данные пользователей третьим лицам;
  • не использует файлы cookie в Приложении.

Всё взаимодействие между устройствами осуществляется напрямую (peer-to-peer) в пределах локальной сети пользователя. Разработчик не имеет технической возможности получить доступ к передаваемым данным.

4. Данные, обрабатываемые GitHub (третья сторона)

Сайт Приложения размещён на платформе GitHub Pages, принадлежащей GitHub, Inc. (дочерняя компания Microsoft Corporation). При посещении Сайта GitHub автоматически собирает технические данные, в том числе:

  • IP-адрес посетителя;
  • тип браузера, версию и операционную систему;
  • реферальный URL;
  • дату, время и продолжительность посещения;
  • файлы cookie, необходимые для работы платформы.

Разработчик не имеет доступа к этим данным и не управляет их обработкой. Данные обрабатываются GitHub в соответствии с их политикой конфиденциальности: GitHub Privacy Statement.

Важно. GitHub, Inc. — американская компания. Обработка данных осуществляется на серверах за пределами России. Согласно ФЗ № 23-ФЗ (вступил в силу 01.07.2025), хранение персональных данных граждан РФ в базах данных за рубежом не допускается. Однако данный запрет распространяется на операторов, осуществляющих целенаправленный сбор и хранение данных — Разработчик таковым не является.

5. Данные внутри Приложения

При использовании Приложения для дистанционного управления компьютером:

  • параметры соединения и настройки хранятся исключительно на устройствах пользователя;
  • передача данных между устройствами происходит напрямую по локальной сети;
  • Разработчик не имеет доступа к передаваемому контенту сессии;
  • Приложение не ведёт логов и не создаёт записей сессий на сторонних серверах.

6. Cookies и отслеживание

Разработчик не использует файлы cookie в Приложении. На Сайте cookie могут устанавливаться исключительно платформой GitHub Pages в соответствии с их политикой (см. раздел 4).

Разработчик не использует системы веб-аналитики (Google Analytics, Яндекс.Метрика и аналогичные).

7. Права пользователей

В соответствии с ФЗ-152 пользователи вправе:

  • получить информацию об обработке своих персональных данных;
  • требовать уточнения, блокирования или уничтожения персональных данных;
  • отозвать согласие на обработку персональных данных.

Поскольку Разработчик не обрабатывает персональные данные пользователей, перечисленные права в отношении Разработчика неприменимы. По вопросам данных, обрабатываемых GitHub, следует обращаться непосредственно в GitHub, Inc.

8. Безопасность

Разработчик не хранит пользовательские данные, что исключает риск их утечки со стороны Разработчика. Безопасность соединения между устройствами зависит от защищённости локальной сети пользователя. Рекомендуется использовать Приложение только в доверенных сетях.

Использование Приложения для несанкционированного доступа к чужим устройствам является нарушением условий использования и может влечь уголовную ответственность по ст. 272 УК РФ.

9. Дети

Приложение не предназначено для лиц младше 18 лет. Разработчик не осуществляет намеренный сбор данных от несовершеннолетних.

10. Изменения Политики

Разработчик вправе вносить изменения в настоящую Политику в связи с изменением законодательства или модели распространения Приложения. Актуальная версия всегда доступна на Сайте. Номер редакции и дата обновления указаны в заголовке документа.

При внедрении платной подписки или любой формы монетизации настоящая Политика будет существенно дополнена разделами об обработке платёжных данных и регистрации в реестре операторов РКН.

11. Применимое право

Настоящая Политика разработана в соответствии с законодательством Российской Федерации, в первую очередь ФЗ-152 «О персональных данных» и ФЗ-149 «Об информации, информационных технологиях и о защите информации».
